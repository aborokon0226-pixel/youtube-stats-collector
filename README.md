# 유튜브 영상 통계 수집기

[![Python](https://img.shields.io/badge/python-3.12-blue)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![Tests](https://img.shields.io/badge/tests-passing-brightgreen)](#4-테스트-실행하기)

유튜브 영상 링크를 입력하면, 조회수를 자동으로 가져와서 **주차별 콘텐츠 마케팅 퍼널 표**(`funnel_report.xlsx`)에 채워주는 프로그램입니다. 매출·클릭율·구독전환율처럼 아직 자동으로 못 가져오는 항목은 표에 빈칸으로 남겨두어, 직접 입력하시면 됩니다.

| 입력 | 처리 | 출력 |
| --- | --- | --- |
| 키콘텐츠 링크, 채널 주소, 주차 번호 | YouTube Data API로 조회수 조회 (풀링 콘텐츠는 채널 전체 영상을 자동 수집) | `funnel_report.xlsx`의 "키콘텐츠 조회수", "풀링 콘텐츠 조회수" 자동 입력 |

## 1. 준비하기

이 프로그램을 실행하려면 Python이 설치되어 있어야 합니다.

필요한 패키지를 설치하세요:

```bash
pip install -r requirements.txt
```

## 2. 유튜브 API 키 설정하기

1. `.env.example` 파일을 복사해서 `.env`라는 이름으로 저장하세요.
2. `.env` 파일을 열어서 아래처럼 본인의 유튜브(구글) API 키를 입력하세요.

```
YOUTUBE_API_KEY=발급받은_API_키
```

3. (선택) 항상 같은 채널을 쓴다면 `DEFAULT_CHANNEL_URL`도 채워두세요. 실행할 때 채널 주소를 물어보는 칸에서 그냥 Enter만 누르면 이 값이 쓰입니다.

```
DEFAULT_CHANNEL_URL=https://www.youtube.com/channel/본인채널ID
```

> `.env` 파일은 절대 GitHub에 올리지 마세요. `.gitignore`에 이미 등록되어 있어 자동으로 제외됩니다.

주차 번호와, 아래 4번 심화 지표에서 쓰는 시작일/종료일도 오늘 날짜를 기준으로 자동 계산되어 기본값으로 제시됩니다. 그냥 Enter를 누르면 그 값을 그대로 씁니다.

## 3. 실행하기

```bash
python youtube_stats.py
```

실행하면 순서대로 물어봅니다:

1. **몇 주차 데이터인가요?** — 숫자만 입력 (예: `1`)
2. **키콘텐츠 링크** — 랜딩페이지로 유입시키는 영상만 한 줄에 하나씩 입력, 다 입력했으면 빈 줄에서 Enter
3. **채널 주소** — `@핸들` 또는 `youtube.com/channel/UC...` 형태로 입력하면, 그 채널의 전체 영상 중 키콘텐츠를 제외한 나머지를 자동으로 "풀링 콘텐츠"로 계산합니다.

예시:
```
몇 주차 데이터인가요? (숫자만 입력, 예: 1): 1
[키콘텐츠] 랜딩페이지로 유입시키는 영상 링크를 한 줄에 하나씩 입력하세요. 없으면 바로 Enter.
https://www.youtube.com/watch?v=dQw4w9WgXcQ
(빈 줄에서 Enter)
[풀링 콘텐츠] 채널 전체에서 자동으로 계산합니다. 채널 주소(@핸들 또는 channel/UC... URL)를 입력하세요: @example_channel
```

실행이 끝나면 `funnel_report.xlsx` 파일에 "키콘텐츠 조회수", "풀링 콘텐츠 조회수" 값이 해당 주차 열에 채워집니다. 같은 파일에 계속 실행하면 주차가 옆으로 하나씩 늘어납니다. 영상별 상세 내역은 "상세 내역" 시트에서 확인할 수 있습니다.

채널 주소를 입력하면 그 채널의 **현재 구독자 수**도 함께 기록됩니다("구독자 스냅샷" 시트). 지난주 기록이 있으면 그 차이로 "월간 구독 증가수"와 "구독전환율"이 자동으로 채워집니다 — 처음 실행할 때는 비교할 이전 기록이 없어서, 구독자 수만 기록되고 다음 실행부터 증가수가 계산됩니다.

**"하루 평균 조회수"와 "48시간 조회수"**도 이번 주 조회수를 바탕으로 자동 계산됩니다. 48시간 조회수는 영상마다 게시 후 정확히 48시간 시점의 조회수를 봐야 정확하지만, 아직 그 데이터는 못 가져와서 하루 평균의 2배로 추정한 값입니다.

## 4. 심화 지표(연계율·유입경로·시청지속시간) 계산하기

"키 콘텐츠 연계율", "시청지속시간", "검색/페이지/탐색 유입"은 채널 소유자만 볼 수 있는 비공개 데이터라, API 키 대신 **구글 로그인(OAuth)**이 필요합니다. 최초 1회만 로그인하면 이후에는 로그인 정보가 저장되어 다시 로그인하지 않아도 됩니다.

> **클릭율(노출 대비 클릭)은 이 방법으로도 못 가져옵니다.** 유튜브가 이 데이터를 API로 아예 공개하지 않아서, 스튜디오 화면에서 직접 확인하는 수밖에 없습니다.
>
> **"탐색 유입"은 근사치입니다.** 유튜브 Analytics API에는 "탐색 기능" 전용 항목이 따로 없어서, 가장 가까운 "구독 피드+홈 화면" 값으로 대신 계산합니다. Shorts 스와이프 등 다른 발견 경로는 포함되지 않습니다.

> 참고: 이 OAuth 로그인은 채널을 실제로 소유한 구글 계정으로 해야 합니다. 유튜브 스튜디오의 "관리자" 초대만 받은 계정으로는 API 접근이 막혀있을 수 있습니다 (화면으로는 다 보여도 API 권한은 별도입니다).

사전 준비(최초 1회):
1. Google Cloud Console에서 프로젝트 생성 → "YouTube Analytics API" 사용 설정
2. "OAuth 동의 화면"에서 외부 유형으로 앱 등록 → 유튜브 채널을 관리하는 구글 계정을 테스트 사용자로 추가
3. "사용자 인증 정보"에서 데스크톱 앱용 OAuth 클라이언트 ID 생성 → JSON 다운로드해서 프로젝트 폴더에 `client_secret.json`으로 저장 (`.gitignore`에 등록되어 있어 GitHub에는 올라가지 않습니다)

실행:
```bash
python analyze_linkage.py
```

브라우저가 열리면 **유튜브 채널을 관리하는 구글 계정**으로 로그인하세요. ("Google에서 확인하지 않은 앱" 경고가 뜨면 "고급" → "~(으)로 이동(안전하지 않음)"을 눌러 진행하면 됩니다.) 브라우저가 자동으로 안 열리면 `auth_url.txt` 파일을 메모장으로 열어 주소를 복사해서 브라우저에 붙여넣으세요.

## 참고

- 조회수, 좋아요수, 댓글수, 게시일, 구독자 수(월간 구독 증가수·구독전환율), 하루 평균/48시간 조회수(추정)는 API 키만으로 가져옵니다 (`youtube_stats.py`).
- 키 콘텐츠 연계율, 시청지속시간, 검색/페이지/탐색 유입은 채널 소유자 OAuth 로그인이 필요합니다 (`analyze_linkage.py`).
- 매출, 객단가, 필요고객수, 유료/무료회원 관련 지표, 랜딩페이지 접속수, 링크클릭율, 클릭율(노출 대비)은 자동화할 수 없어 표에 직접 입력해야 합니다 (랜딩페이지·결제 데이터가 필요하거나, 유튜브가 API로 공개하지 않는 항목).
